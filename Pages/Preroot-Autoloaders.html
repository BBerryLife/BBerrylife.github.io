Pre-rooted Autoloaders – Firmware Đã Được Root Sẵn Cho BlackBerry 10

Cập nhật lần cuối: 22/10/2026
Caution – Cảnh báo: Sử dụng theo rủi ro của bạn. Tác giả không chịu trách nhiệm về bất kỳ thiệt hại trực tiếp hoặc gián tiếp nào phát sinh từ việc sử dụng các phiên bản đã chỉnh sửa này. Ngoài ra, hãy dành 1 sự cảm ơn to lớn và sâu sắc đến "cha đẻ" của việc root trên BB10 - Oleksandr.

Pre-rooted Autoloaders Là Gì?

Đây là bộ sưu tập các firmware BlackBerry 10 đã được tích hợp sẵn quyền root. Thay vì phải thực hiện các bước root phức tạp sau khi cài đặt, bạn chỉ cần flash firmware này và thiết bị sẽ tự động có root ngay sau khi khởi động lần đầu.

Điểm Mới Trên Bản V4 (What's New)

  • Phương pháp tích hợp hệ thống mới: sử dụng lỗ hổng Dynamic Library Hijacking trên BlackBerry 10 (bài phân tích kỹ thuật). Root được giữ nguyên sau khi khởi động lại — việc reboot thiết bị trước khi có root sẽ không còn làm hỏng quá trình.
  • Lưu ý quan trọng: cơ chế tích hợp hoạt động thông qua AppWorld. Không thêm sys.appworld vào lệnh removeapp, nếu không cơ chế sẽ bị hỏng.
  • Ổn định & tối ưu mã: loại bỏ hoàn toàn việc dùng switchzone làm trigger chạy mã có quyền root, đồng thời viết lại toàn bộ btool bằng C, khắc phục các lỗi crash Android Runtime và thiết bị tự khởi động lại.
  • Mở rộng btool: btool viết bằng C nay tích hợp sẵn trình patch pathtrust, trình patch launcher và công cụ sao lưu NVRAM.
  • Bảo mật & tinh chỉnh hệ thống: gỡ bỏ phần lớn các helper suid/sgid không cần thiết, chỉ giữ lại mức tối thiểu để nâng quyền. Có thể cài ứng dụng BAR unsigned ngay khi nhận được thông báo xác nhận root.

Trình Cài Đặt Patch Hệ Thống (Đang Phát Triển)

V4 giới thiệu trình cài đặt patch hệ thống, có khả năng chỉnh sửa các tệp hệ thống chỉ đọc, file nhị phân và thư viện động.

Chưa phát hành: tính năng này cho phép hồi sinh các dịch vụ cũ — gồm BBID, Weather, AppWorld và BBM — bằng cách chuyển hướng chúng sang các máy chủ cộng đồng thay cho hạ tầng RIM/BlackBerry đã ngừng hoạt động. Đặc biệt cảm ơn @He11kern vì những đóng góp này.

Cách Sử Dụng

Quy trình cài đặt rất đơn giản:

  1. Flash thiết bị bằng autoloader phù hợp với model của bạn.
  2. Chờ thiết bị khởi động và thông báo "The device has been successfully rooted!" xuất hiện.
  3. Xong — thiết bị của bạn đã có root và sẵn sàng sử dụng!

Truy Cập SSH

Thêm Authorized SSH Keys

Private key mặc định được lưu trong id_rsa4x. Nếu muốn dùng SSH key riêng, hãy đặt public key của bạn vào:

patchdata/var/etc/ssh/authorized_keys2

Sau đó bỏ comment các dòng sau trong patch.txt:

push "patchdata/var/etc/ssh/authorized_keys2" "/var/etc/ssh/authorized_keys2"
chmod 644 "/var/etc/ssh/authorized_keys2"
chown 0:0 "/var/etc/ssh/authorized_keys2"

Giữ Nguyên SSH Host Keys

Theo mặc định, SSH host key có thể thay đổi sau khi flash lại, khiến client hiện cảnh báo fingerprint mới. Để giữ nguyên host key qua các lần flash, hãy bỏ comment:

push "patchdata/var/etc/ssh/ssh_host_rsa_key" "/var/etc/ssh/ssh_host_rsa_key"
push "patchdata/var/etc/ssh/ssh_host_rsa_key.pub" "/var/etc/ssh/ssh_host_rsa_key.pub"
chmod 600 "/var/etc/ssh/ssh_host_rsa_key"
chown 0:0 "/var/etc/ssh/ssh_host_rsa_key"
chmod 644 "/var/etc/ssh/ssh_host_rsa_key.pub"
chown 0:0 "/var/etc/ssh/ssh_host_rsa_key.pub"

Bạn cũng có thể thay các file này bằng cặp SSH host key sẵn có của mình để giữ nguyên fingerprint.

Tạo Firmware Tùy Chỉnh Trong 1 Bước (bb10mt)

Tham số batch mới của bb10mt cho phép patch và root một file autoloader firmware chỉ trong một bước tự động, không cần viết script thủ công.

Windows:

bb10mt.exe batch -i Z30_10.3.03.3216_STA100-1-2-3-4-5-6.exe -s patch.txt -o \tmp\z30root

Linux / macOS:

./bb10mt batch -i Z30_10.3.03.3216_STA100-1-2-3-4-5-6.exe -s patch.txt -o /tmp/z30root

Sau khi chạy xong, trong thư mục đầu ra (-o) sẽ có các file kết thúc bằng _os.exe và _radio.exe; các file còn lại chỉ là kết quả trung gian và có thể xóa. Để cài đặt, chạy _os.exe trước (cuối quá trình sẽ hiện lỗi — đây là bình thường, hãy bỏ qua), rồi chạy _radio.exe.

Cấu Hình Patch Phân Vùng User (patch.txt)

File patch.txt truyền qua tham số -s chứa các chỉ thị dùng để chỉnh sửa phân vùng user khi dựng image hoặc khi hệ thống khởi động:

  • touch /var/rootdata/use.root — bật các helper root cơ bản; thêm các binary SUID/SGID __root và u_root vào pathtrust.
  • touch /var/rootdata/use.sshd — tự động chạy sshd với quyền root khi khởi động.
  • #touch /var/rootdata/use.berrycore — thêm thư mục gốc (/) vào pathtrust để các ứng dụng phụ thuộc BerryCore chạy được với quyền root (tắt theo mặc định; các bản sau sẽ chỉ tin cậy các binary BerryCore cụ thể).
# Enable base root helpers (__root, u_root)
touch /var/rootdata/use.root

# Auto-start SSH daemon as root
touch /var/rootdata/use.sshd

# BerryCore application execution (disabled by default)
#touch /var/rootdata/use.berrycore

Nâng Cấp Không Cần Flash Lại

Những người ủng hộ (supporter) và contributor có thể xin script nâng cấp để chuyển bản AutoRoot đã cài sang V4 mà không cần flash lại firmware. Chép file v2tov4.sh hoặc v3tov4.sh vào thiết bị rồi chạy bằng sh /path/to/file/v2tov4.sh (hoặc v3tov4.sh). Script có thể hỏi bạn có cần quyền root và sshd hay không; sau khi chạy thành công, hãy khởi động lại thiết bị.

Nếu bạn đang kết nối SSH với quyền root, đừng chạy script trực tiếp bằng user root. Hãy chạy qua shell wrapper __devuser, hoặc thêm script vào pathtrust:

/proc/boot/pathtrust !/path/to/script/v2tov4.sh
/proc/boot/pathtrust !/path/to/script/v3tov4.sh

Đặc Tả Gói Hệ Thống (System Package)

Một gói chứa các file cấu hình, script và tài nguyên đích, được chia theo từng giai đoạn thực thi:

pkg.bar             # Original BAR package (optional)
MANIFEST            # Package manifest file

├── data/           # Main installation payload
│   ├── file1..fileN# Payload files
│   ├── perms       # File permissions for data/
│   ├── links       # Symlinks, copies, PPS objects, folder creation
│   ├── patch       # Binary byte-patching instructions
│   └── trusted     # Paths to be added to trustpath
│
└── init/           # Initialization stage (root startup)
    ├── file1..fileN# Required startup files
    ├── start.sh    # Shell script triggered on root start
    ├── perms       # File permissions for init/
    ├── links       # Symlinks/copies for the init stage
    ├── patch       # Binary patches applied during init
    └── trusted     # Trustpath rules for the init stage
  • links — thao tác hệ thống tệp: ln:src:dst (symlink), cp:src:dst (sao chép), pps:src:dst (tạo/cập nhật đối tượng PPS), md:dst (tạo thư mục).
  • perms — quyền sở hữu và chế độ truy cập (tương đương chmod/chown), định dạng /path/to/target:UID:GID:MODE, ví dụ /accounts/1000/appdata/test:0:0:0755.
  • patch — thay thế ở mức byte trong file nhị phân đích: một dòng đường dẫn file, theo sau là các dòng 0xADDR: 0xOLD 0xNEW, ví dụ 0x0001A2F0: 0x89 0x90.
  • trusted — file văn bản thuần; mỗi dòng là đường dẫn tuyệt đối tới binary hoặc thư viện cần thêm vào trustpath của hệ thống.
